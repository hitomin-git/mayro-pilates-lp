# Mayro HP 再現版

2026年9月24日に公式サイト https://mayro-pilates.com/ から回収した構成・文章・画像・スタイルをもとにした、確認用の静的サイトです。

## 確認する

`node serve-hp.cjs` を実行して http://127.0.0.1:4184/hp/ を開きます。

`dist/hp/index.html` を直接開くこともできます。ビルドや外部CMSへの接続なしで表示できます。

## LPと同じGitで管理する配置

既存LPリポジトリ `hitomin-git/mayro-pilates-lp` の直下へ、このフォルダの内容を追加します。

| パス | 内容 |
|---|---|
| `dist/hp/` | HPの15ページ、CSS、操作用JavaScript、ローカル画像・フォント |
| `hp-source/views/` | 元サイトの全15構成定義と共通部品5件。試験ページ・スマホメニューも保存 |
| `hp-source/site-data.json` | 元サイトのページ一覧、配色、文字設定、公開スナップショット情報 |
| `hp-source/assets.json` | 公式画像URLとローカルファイルの対応 |
| `hp-source/page-inventory.json` | 15ページのURL・配置先・文章一覧 |
| `build-hp.cjs` | 回収データを静的HTML/CSSに変換する生成処理 |
| `check-hp.cjs` | ページ内リンク・画像参照・未展開文字列の検査 |
| `serve-hp.cjs` | ローカル確認用サーバー |

既存の `dist` を公開する方式で、HPは `/hp/` に追加されます。確認用URLは https://hitomin-git.github.io/mayro-pilates-lp/hp/ 。検索除外を維持し、公式ドメインの本番HPとは分離しています。LPの更新手順はルートの `README.md` を参照してください。

## 編集する

ページの文章・余白・画像指定は `hp-source/views/` に保存されています。ページとファイル名の対応は `hp-source/site-data.json` の `pinia.productStore.product.pages` を参照します。ページの `uuid` に対応するJSONを編集して `node build-hp.cjs` を実行してください。ニュース1件の本文・日付は生成処理の `article` にあります。

全体の追加調整は `dist/hp/base.css`、FAQ・メニュー・スライド・確認用フォームの操作は `dist/hp/site.js` です。生成HTMLへの直接変更は再生成で上書きされます。

`node check-hp.cjs` で参照切れを確認します。追加した日本語を表示する際は、今回収録した文字以外には端末標準フォントが使われます。フォントを追加更新する場合は別途全文字版への差し替えを検討してください。

## 再現範囲と公開前の残作業

- レイアウト、文章、価格、19点の画像、配色、レスポンシブの設定、ニュース本文1件を回収。
- 表示用の画像は長辺2200px以内へ圧縮し、画像合計を約193MBから約4.2MBへ軽量化。元URL対応と圧縮記録は `hp-source/` に保存しています。
- FAQは標準の開閉、モバイルナビはダイアログ、レビューは左右操作と横スワイプ、トップ画像は4秒切替として実装。元サービスの動きと完全同一ではありません。
- 予約・お問い合わせの旧フォームは表示確認用で、入力値を送信・保存しません。正式運用時には送信先・通知・個人情報の取り扱いの設定が必要です。現行 `/reserve-1/` の外部予約・LINEへの導線は元サイトのリンクを引き継ぎます。
- 元サイト内でLINEのリンク先とInstagramのアカウント表記に複数の種類が残っています。独自に統一していません。正式な窓口を決めてから統一してください。
- 元サイトの非表示・旧ページにはエステ用の項目などが残っています。保存目的で再現していますが、公開メニューへ追加していません。
- 元サイトの計測タグ、Studio実行環境、CMS通信は組み込んでいません。ニュースは保存した静的内容です。
- 全ページに検索除外 `noindex,nofollow` を設定しています。独自ドメインへの切替、正式なSEO設定、計測・フォーム接続は本公開時の作業です。
- 元ページの公開状態を全画素で比較した完全な複製ではありません。PCトップ・スマホ料金ページなどを目視し、機能と参照先を検査した初期再現版です。
