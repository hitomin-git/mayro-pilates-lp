# Mayro Pilates LP

Mayroの広告向けランディングページの仮案。
女性専用・個別のマシンピラティスを、短いストーリーで紹介します。

## 編集と公開

- `dist/index.html`: コピーと構成
- `dist/style.css`: スマホ・PCのデザイン
- `dist/assets/`: 公式サイト由来のロゴと写真
- `node serve.mjs`: ローカル確認（http://127.0.0.1:4173）

ソースはmasterで管理し、distの内容をgh-pagesブランチのルートに反映してGitHub Pagesで公開します。

更新時はmasterをコミットしてpushした後、`git subtree push --prefix dist origin gh-pages`で公開内容を更新します。

## 仮原稿の確認事項

- 「約60分」は依頼者の記憶をもとにした仮表記です。
- 「有料体験と同じクオリティ」は依頼者の認識をもとにした仮原稿です。
- 広告配信前に所要時間・体験条件・案内内容を確定してください。
